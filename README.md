# 12 घंटे — Starter Demo

यह एक शुरुआती, मोबाइल-फ्रेंडली शॉपिंग वेबसाइट डेमो है। इसे मुफ्त में ब्राउज़र में चलाया जा सकता है।

## चलाने का तरीका
1. ZIP खोलें।
2. `index.html` पर टैप/डबल-क्लिक करें या उसे ब्राउज़र में खोलें।
3. प्रोडक्ट जोड़ें, कार्ट देखें और टेस्ट ऑर्डर करें।

कुछ मोबाइल ब्राउज़र `file://` से सभी सुविधाएँ नहीं चलाते। ऐसे में मुफ्त static hosting (जैसे GitHub Pages) पर डालना बेहतर है।

## जरूरी बातें
- प्रोडक्ट, कीमत और emoji `app.js` में उदाहरण हैं; उन्हें अपने असली स्टॉक से बदलें।
- यह केवल फ्रंट-एंड डेमो है। ऑर्डर सिर्फ उसी डिवाइस के ब्राउज़र में localStorage में सेव होता है।
- दुकान को कोई ऑर्डर, SMS, WhatsApp या ईमेल अपने-आप नहीं भेजा जाता।
- लाइव उपयोग से पहले सर्वर/डेटाबेस, सुरक्षित admin login, privacy notice, stock control, order notifications, payment integration और delivery workflow जोड़ना होगा।
- अभी ग्राहक की असली जानकारी इकट्ठा न करें; डेमो के लिए काल्पनिक जानकारी इस्तेमाल करें।
- 12 घंटे की डिलीवरी केवल उस पते पर वादा करें जहाँ स्टॉक और डिलीवरी क्षमता की पुष्टि हो।
- Android ऐप पैकेज बनाने के लिए बाद में PWA/TWA या Capacitor जैसी प्रक्रिया अपनाई जा सकती है। इस ZIP में तैयार APK शामिल नहीं है।
